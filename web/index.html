ITS-G5 Empfänger – Web-Flasher

Firmware für den ESP32-C5-LCD-2.73 direkt aus dem Browser installieren.

Was ist das?

Der ESP32-C5-LCD-2.73 empfängt ITS-G5 (IEEE 802.11p, 5,9 GHz) und dekodiert C-ITS-Nachrichten: CAM, DENM, MAPEM und SPATEM. Das 320×320-Display zeigt Status, Stationen, Warnungen und – bei Ampelkreuzungen – den Signalzustand jeder Fahrspur. Optional gibt es eine USB-Rohdatenausgabe und ein pcap-Log auf der SD-Karte.

Voraussetzungen

  • Browser mit Web Serial bzw. WebUSB: Chrome oder Edge (am Desktop; Chrome für Android per WebUSB möglich). Firefox und Safari werden nicht unterstützt.
  • USB-C-Datenkabel (nicht nur Ladekabel).
  • Die Seite muss über HTTPS aufgerufen werden (GitHub Pages erfüllt das).
Dieser Browser unterstützt weder Web Serial noch WebUSB. Bitte Chrome oder Edge am Desktop verwenden oder die Firmware manuell mit esptool flashen (siehe unten).

Installation

  1. Gerät per USB-C mit dem Computer verbinden.
  2. Wenn im Auswahlfenster kein Port erscheint: BOOT gedrückt halten, das USB-Kabel aus- und wieder einstecken und BOOT erst danach loslassen (Download-Modus).
  3. Auf Firmware installieren klicken und den Port des Geräts (USB-JTAG/Serial) auswählen.
  4. Optional Erase device ankreuzen: empfohlen bei der Erstinstallation, nicht bei Updates, da dabei auch die gespeicherten Einstellungen (NVS) gelöscht werden. Warten, bis die Installation abgeschlossen ist; das Gerät startet danach neu.
Dieser Browser wird nicht unterstützt. Die Installation ist nur über HTTPS oder localhost möglich.

Fehlerbehebung

Der Port wird nicht angezeigt

Anderes USB-Kabel oder anderen Port probieren. BOOT halten, während das Kabel eingesteckt wird, um den Download-Modus zu erzwingen. Unter Linux ggf. Mitglied der Gruppe dialout werden.

Verbindung bricht ab oder Installation schlägt fehl

Andere Programme schließen, die den Port nutzen (Serial-Monitor, Terminal). Geräte-Reset durchführen und erneut starten, ggf. mit gedrückter BOOT-Taste.

Das Display bleibt dunkel

Nach der Installation einmal USB trennen und wieder verbinden. Prüfen, ob die Installation vollständig durchlief.

Manuell flashen

esptool.py --chip esp32c5 write_flash 0x0 firmware-factory.bin – das Image gibt es auch bei den Releases.
